OSI Model
----------
OSI model (Open System Interconnection)
physical : binary,hubs,repeaters
datalink : framerelay,switches,atm,ethernet
network : ipv4 ipv6 ipx ipsec routers
transport : tcp,udp,spx
session : control sessions between applications
presentation : ascii,gif,mpeg
application : ftp,dns,http,dhcp,telnet
